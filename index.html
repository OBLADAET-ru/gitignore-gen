Возможности

Что утилита делает за вас

Никаких шаблонов с toml.io и ручного слияния секций: детектор, библиотека шаблонов и writer работают как один конвейер.

IDE и ОС по умолчанию

Детерминированный вывод

sortKeys() приводит шаблоны к фиксированному

sortKeys() приводит шаблоны к фиксированному порядку, поэтому повторная генерация даёт идентичный файл — удобно для code review.

Защита от перезаписи

Если .gitignore уже существует, утилита не тронет его без флага --force. Флаг --dry-run покажет результат, ничего не записывая.

⚡

Ноль зависимостей

Только стандартная библиотека Node.js: fs, path, process. Быстрый старт, маленький bundle, никаких supply-chain сюрпризов.

Как работает

      
Три шага от директории к файлу

      

        Конвейер разбит на чистые функции: детекция, сборка шаблонов,
        сериализация. Каждый этап тестируется отдельно.
      


      

        

          src/detector.ts
          
Сканирование

          

            Читает содержимое корня проекта, сопоставляет имена с таблицей
            правил и возвращает список обнаруженных стеков.
          

        

        

          src/templates/
          
Сборка шаблонов

          

            Для каждого стека берётся объект шаблона, секции объединяются,
            дубликаты удаляются, IDE и ОС добавляются по флагам.
          

        

        

          src/writer.ts
          
Запись

          

            Сериализует дерево в текст с заголовками-комментариями,
            проверяет существующий файл и пишет результат с учётом
            --force / --dry-run.
          

        

      


      

        

          

            detector.ts
            
          

          
const RULES: Rule[] = [
  { stack: "node",    files: ["package.json", "tsconfig.json"] },
  { stack: "python",  files: ["pyproject.toml", "requirements.txt"] },
  { stack: "go",      files: ["go.mod"] },
  { stack: "rust",    files: ["Cargo.toml"] },
  { stack: "java",    files: ["pom.xml", "build.gradle"] },
  { stack: "docker",  files: ["Dockerfile", "docker-compose.yml"] },
];

export function detectStacks(root: string): Stack[] {
  const entries = new Set(readdirSync(root));
  return RULES
    .filter(r => r.files.some(f => entries.has(f)))
    .map(r => r.stack);
}

        


        

          

            writer.ts
            
          

          
export function serialize(
  tree: TemplateTree,
  opts: { comments: boolean; sort: boolean }
): string {
  const out: string[] = [];
  for (const [section, patterns] of Object.entries(tree)) {
    if (opts.comments) out.push(`# ${section}`, "");
    const list = opts.sort ? [...patterns].sort() : patterns;
    out.push(...list, "");
  }
  return out.join("\n").trimEnd() + "\n";
}

        

      

    

  


  

    

      
CLI

      
Команды и флаги

      

        Утилита работает без аргументов — в текущей директории. Все флаги
        опциональны и комбинируются.
      


      

        

          

            Установка и базовый запуск
            
          

          
# глобально
npm install -g gitignore-gen

# или через npx
npx gitignore-gen

# в конкретной директории
gitignore-gen ./my-project

# предпросмотр без записи
gitignore-gen --dry-run

# перезаписать существующий файл
gitignore-gen --force

        


        

          

            Флаги
            
          

          
--dry-run      показать результат, не писать файл
--force        перезаписать существующий .gitignore
--no-ide       не добавлять секции IDE
--no-os        не добавлять секции ОС
--stacks a,b   явно указать стеки
--list         показать доступные шаблоны
--help         справка
--version      версия
